# Emma Déco

Site vitrine d'Emma Déco — décoration d'événements et d'intérieur, Yopougon Toit Rouge, Abidjan.

- Un seul fichier : `index.html` (HTML/CSS/JS, aucune installation).
- Photos : à mettre dans `images/`, puis à déclarer dans le tableau `PHOTOS` en bas de `index.html`.
- WhatsApp : constante `WA` dans `index.html`.
- Mise en ligne : GitHub Pages (Settings → Pages → branche `main`, dossier `/`).
